# Pixel Puzzle

A cozy pixel-art jigsaw puzzle game built with **Godot**.

Convert images into pixel art and solve them by dragging each piece back to its correct position. The game is designed to be simple, relaxing, and expandable with different puzzle sizes, difficulties, and game modes.
You can upload your picture or any moment you capture with families, love ones, with dogs, or cats, or any animals
---

## Features

* 🧩 Drag-and-drop puzzle pieces
* 🎨 Automatic pixel-art image conversion
* 🖼️ Ghost image preview for easier placement
* 📏 Multiple puzzle grid sizes
* 📌 Piece snapping when placed close enough
* ✅ Puzzle completion detection

---

## Built With

* Godot
* GDScript

---

## How to Play

1. Start the game.
2. Drag puzzle pieces around the board.
3. Place each piece near its correct position.
4. Pieces automatically snap into place.
5. Complete the entire image to win.

---

## Controls

| Action        | Input                     |
| ------------- | ------------------------- |
| Pick up piece | Left Mouse Button         |
| Drag piece    | Mouse                     |
| Drop piece    | Release Left Mouse Button |
